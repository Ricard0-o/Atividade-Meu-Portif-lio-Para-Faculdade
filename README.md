# Portfólio acadêmico — CP3

Evolução do portfólio pessoal de Ricardo Nelber para a terceira entrega de Desenvolvimento Front-End para Web.

## Páginas

- `index.html`: apresentação e projetos;
- `curriculo.html`: formação e trajetória;
- `formulario.html`: contato com validação e rascunho persistente;
- `multimidia.html`: galeria de projetos;
- `graficos.html`: visualizações feitas com HTML, CSS e SVG.

## Recursos da CP3

- navegação responsiva entre as cinco páginas;
- preferência de tema salva em `localStorage`;
- formulário com validação, mensagens de erro e feedback visível;
- rascunho do formulário salvo e restaurado pelo navegador;
- estilos em `css/estilos.css` e scripts em `js/scripts.js`;
- publicação por GitHub Pages com HTTPS.
