# Prompt para estudar e preparar o vídeo do CP4

Atue como tutor de front-end. Leia o repositório https://github.com/Ricard0-o/Atividade-Meu-Portif-lio-Para-Faculdade/tree/cp4-entrega e o site https://ricard0-o.github.io/Atividade-Meu-Portif-lio-Para-Faculdade/. Explique em português simples como HTML, CSS, Bootstrap e JavaScript se conectam neste projeto. Use exemplos concretos dos arquivos; não invente funções nem histórico. Confira todos os critérios descritos em docs/PLANO_CP4.md.

Depois, prepare um roteiro em tópicos para um vídeo de aproximadamente dois minutos (limite obrigatório: 1min30–2min30). O vídeo deve mostrar o site publicado em funcionamento, navegar nas cinco páginas, demonstrar uma feature JavaScript e explicar a evolução CP1–CP4, layout, responsividade, acessibilidade, Bootstrap e uso/revisão de IA. Se o histórico não comprovar CP1 ou CP2, indique o que preciso confirmar. Faça perguntas curtas para verificar meu entendimento. Não escreva afirmações falsas sobre minha autoria ou minha revisão.

## Roteiro sugerido — 2 minutos
- 0:00–0:15: início publicado, objetivo e identidade visual.
- 0:15–0:35: visitar currículo, multimídia e gráficos; explicar organização em cinco páginas.
- 0:35–1:05: formulário: provocar erro, preencher dados fictícios e recarregar para mostrar rascunho; validar a mensagem. Explicar localStorage e ausência de envio externo.
- 1:05–1:25: alternar tema, reduzir janela e mostrar menu; usar Tab e Escape para evidenciar teclado e foco. Explicar contraste e alt.
- 1:25–1:45: explicar Bootstrap Utilities no cabeçalho: d-flex, align-items-center e justify-content-between. CSS próprio mantém a identidade.
- 1:45–2:00: explicar evolução com etapas confirmadas; mencionar assistência de IA e o que você efetivamente revisou; apontar repositório/tag.

Antes de gravar: revisar os arquivos, confirmar evolução CP1/CP2, limpar dados reais do formulário e ensaiar com cronômetro. Mostrar o site publicado; vídeo apenas de slides ou editor não atende. Depois: testar acesso ao vídeo sem login, conferir duração e permissões, inserir o link real na resposta.
